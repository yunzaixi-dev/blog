上一篇[按版块拆类型](/posts/nodeseek-post-types/)把站点的 `cat` 当成了主轴，但版块是发帖入口，不等于内容。日常区里既有 VPS 闲聊，也有 AI 求助；交易区几乎全是买卖，主题却是 VPS、账号、域名各不相同。这一篇改成：**只根据标题正则，给每帖一个互斥的内容主类**（可附带次要标签），再统计占比和互动。

数据与[时段活跃度](/posts/nodeseek-online/)同源：公开列表 **45,420** 帖，抓于 **2026-10-17 00:23～01:00（北京时间）**，未登录。

## 方法

- **主类**：15 类规则按优先级首次命中即为主类——意图类（曝光 / 交易 / 拼车 / 测评 / 新人灌水）优先于话题类（AI / VPS / 机场 / …），因此「`[出]` 一台 VPS」→ **交易买卖**，次要标签可记 VPS。
- **未命中** → **其他**（全库 30.9%；近窗 29.2%）。命名覆盖全库 **69.1%**（31,370 / 45,420）。
- **发帖量**：高流量版块抓取约 100 页封顶，历史深度不可比。发帖结构只用 **发帖年龄 ≤ 84 小时** 的 **7,935** 帖。
- **互动**：浏览 / 评论**中位数**用全样本；讨论热度（评论÷浏览）用发帖满 24h 子集。
- **不做**：不读帖正文（本机访问会被 Cloudflare 拦）；不把版块字段写入分类器（热力图仅作对照）。

规则摘要见文末；完整正则在分析脚本里。

## 小结

1. **量（近窗）**：在能命名的帖里，交易、AI、VPS、求助、测评是五大内容；版块上的「日常 54%」其实是这些话题的混合入口。
2. **质（阅读）**：曝光骗子中位浏览遥遥领先；支付 / 羊毛 / 域名 / 教程次之；测评量大但单帖冷；新人灌水最冷。
3. **质（讨论）**：求助、交易更爱聊；测评、羊毛更偏浏览。
4. **买卖的货**：交易主类约一半标题同时命中 VPS。

## 局限

- 只看标题，谐音 / 无关键词 / 纯表情标题会进「其他」。
- 近窗约 3.5 天；周末结构可能不同。
- 优先级是启发式：话题类（AI / VPS…）排在求助之前，所以「怎么选 VPS」会标成 **VPS**，求助进次要标签；反之若只想把问句都归求助，需要调换规则顺序。
- `\b` 在中文旁不可靠，脚本改用「仅相对拉丁字母数字」的边界；仍可能漏标嵌在品牌名里的词。
- 已删帖不在列表中；浏览数含刷新与爬虫。

接上一篇[各时段活跃度](/posts/nodeseek-online/)。同一份公开列表数据（45,420 帖，抓于 2026-10-17 00:23～01:00 北京时间），这次按**类型**拆：先看站点版块字段，再在标题上叠一层关键词标签。

## 方法（先读这个）

- **主分类**：列表页的 `cat` 字段，共 12 个版块（日常 / 交易 / 测评 / 情报 / 技术 / 推广 / 拼车 / 生活 / 曝光 / 沙盒 / 贴图 / Dev）。
- **发帖量对比窗口**：高流量版块抓取上限约 100 页 × 50 帖 ≈ 5,000，日常、交易等历史深度不可比。因此发帖量只用**发帖年龄 ≤ 84 小时**（约 3.5 天）的 7,935 帖，这个窗口里各版块都还在页数上限之内。
- **互动指标**：浏览 / 评论的**中位数**用全样本；讨论热度（评论÷浏览）只用发帖满 24 小时的帖，减少「刚发出还没人回」的干扰。
- **标题关键词**：多标签正则启发式（一帖可多个），规则写在文末。全库命中率 **59.5%**（27,007 / 45,420）；未命中不等于「无类型」，只是标题没命中现有规则。

数字全部来自本地 `posts.csv`，没有再登录站点。

## 小结

1. **量**：近窗新帖以日常（约一半）和交易（约四分之一）为主。
2. **质（阅读）**：曝光最吃浏览与评论；情报、Dev、贴图次之；推广最冷清。
3. **质（讨论密度）**：日常 / 生活单位浏览带来的回复更多。
4. **标题语义**：AI、求助、测评、VPS、拼车是高频话题；「骗子 / 曝光」类标题阅读最高。

## 局限

- 近窗只有约 3.5 天，周末结构可能不同。
- 高流量版块全样本深度被 100 页上限截断；中位数仍可跨版块比，但「全站历史占比」不能直接用全库帖数去比。
- 标题规则是启发式，同义词 / 谐音 / 无关键词标题会漏标；覆盖率 59.5%。
- 已删帖不在列表中；浏览数含刷新与爬虫，与上一篇相同。
